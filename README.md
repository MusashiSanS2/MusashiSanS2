Sou MusashiSanS2, também conhecido como eoMiggs, desenvolvedor full-stack autodidata com interesse em inteligência artificial, automação, desempenho de sistemas e arquitetura de software. - Interesses: agentes de IA, computação heterogênea, otimização de Windows/Linux e sistemas distribuídos.
